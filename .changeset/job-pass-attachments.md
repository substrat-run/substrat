A job's pass now has `attachments()`, the module's system file surface (`open` and `remove`) for the run's scope, beside `scope()`. A deployed vertical can run retention from a job without a harness of its own. On the hosted adapter both share the pass's system door, so a held module defers the pass instead of spending its retries. A scope sweeper's `startJobs` hook can call the new optional `host.startJobRun`.
