Generated builds write their migrations from the model, put an action on one row in that row with what it changes shown beside it, and offer every operation that changes data on a screen, unless the project's host code calls it or the app marks it `api-only`. A build is refused when a package.json script runs a JavaScript or TypeScript file under `src/` the project does not have, or when `runtimeNeeds` is not what `substrat push` reads. Builds on Workers AI models run: one system message where a host accepts only one, a stream that goes silent is abandoned and retried, a rate limit is waited out longer (5 s doubling to 90 s), and a response whose body cannot be read is retried instead of ending the build.
