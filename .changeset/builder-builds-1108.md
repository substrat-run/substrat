Generated builds write their migrations from the model, put an action on one row in that row with what it changes shown beside it, and offer every operation that changes data on a screen. A build is refused when a package.json script runs a file the project does not have, or when `runtimeNeeds` is not what `substrat push` reads. Builds on Workers AI models run: one system message where a host accepts only one, and a stream that goes silent is abandoned and retried.
