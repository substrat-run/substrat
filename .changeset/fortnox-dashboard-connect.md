financial years — so the dashboard's Connect button and the local script are the same

connect screen can show WHICH company was just attached (the wrong-company-switcher
check).

identifiers whole, the client secret reduced to its last four), and the mock grows an
authorization-code branch whose consent code spends on first use exactly as
