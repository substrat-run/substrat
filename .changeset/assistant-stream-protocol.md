Adds the assistant's stream protocol, **experimental**, at the subpath `@substrat-run/contracts/assistant-stream` (not exported from the package root, and still free to change there). It holds `assistantStreamBody` and `assistantStreamEvent` (the events a chat thread is made of: user message, turn start and finish, steps, text, tool calls, approval requests and their resolution, sources, provenance and budget notices); `readAssistantStreamEvent`, which a client reads with, so an event type or enum value it does not know is skipped rather than thrown on; and `isRestingEvent` and `ASSISTANT_STREAM_VERSION`, which a stream states on `turn-start`. It also holds `approvalDigest` and its own encoding, `approvalEncoding`. The digest is the SHA-256 an approval is bound to: a tagged tuple of the deployed version, the approver, the thread, the step, the call, the operation, the expiry, a nonce and the input, pinned by fixed vectors. Events are size-bounded, and a source link must be `http(s)`. Nothing existing changes.
