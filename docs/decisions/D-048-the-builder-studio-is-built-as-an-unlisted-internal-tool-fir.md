# D-48 — The builder studio is built as an unlisted internal tool first

> **Ratified 2026-08-19.** Transcribed from docs/architecture/builder/studio.md §13 during the Phase-2 log
> split, which found this decision built but never written into the log. The text is
> the author's; only the id is new.

**The builder studio is built as an unlisted internal tool first.** No marketing surface, no dashboard entry, staff roster only; the competent-reviewer problem is solved by construction because every user is staff. Offering it outside the staff roster is a separate decision that re-opens §6, not a deploy.

## Why

The local loop already serves engineers, so the only hypothesis worth testing is whether a *non-engineer domain expert* can reach a staff-admittable vertical — which is simultaneously the internal workflow and the product question, testable against our own operator work rather than a paying customer.
