# K-14 — Shared money schema in @substrat-run/contracts

Shared `money` schema in @substrat-run/contracts: decimal-string amount + ISO 4217 code, branded; engines never invent money representations

## Why

Multi-currency evidence (SEK/NOK) + Tier 1/Tier 2 reconciliation needs uniform money handling
