# Week 34 · 17–23 August 2026

Ninety-one merges, and one argument running through most of them: **a second
description of a declared thing drifts, and nothing was checking.** The manifest,
the migration journal, the OpenAPI document, the browser client and the route
table were all hand-written restatements of facts `spec/model.ts` already held.
By Sunday, none of them were. Alongside that, two changes to what module code may
do — engine calls got a transaction boundary, and the wall clock was taken away.

## The model became the thing everything else is derived from

A vertical has always declared its entities and operations. This week that
declaration stopped being documentation and started being the source.

`@substrat-run/contracts` grew the pieces the derivation needed: an entity
registry the manifest's entity names are checked against ([#702]), `parents`
as an allowlist rather than a single edge ([#713]), relations with both sides
checked against the engines a vertical composes ([#714]), the operation surface
itself ([#708]), `defineOperations` learning those composed engines ([#729]), a
permission declaring what it checks against ([#746]), and `renamedFrom` — the one
declaration a diff genuinely cannot derive.

Then everything adopted it. The engines declared their entities and row schemas —
protocol ([#712], [#758]), invoicing ([#720]), work orders ([#715], [#757]),
absence, booking and invites ([#724]) — and Callout ([#704], [#710]) and
Handlebar ([#705], [#717]) bound their handlers to the declarations, eleven
operations each. Meridian, RallyPoint, the shop and Manyfold followed ([#725]).
The kernel began typing consumers against the engines a vertical actually
composes ([#700]).

`emitTables` and the new `@substrat-run/model-emit` package turned the model into
DDL ([#731]), with a composite key fix and a refusal to store a bare boolean
([#748]). [#733] built a vertical *forward* from a one-line brief to find out what
the derivation actually costs — the existing six demos all had their models
retrofitted, so every check we had was asking the backward question. And [#842]
retired two more hand-maintained files: the browser client and the route table.
That one has a cautionary tale attached. `demos/todo/app/src/api.ts` was 91 lines
a person maintained by remembering to; when [#811] made a read paged and [#827]
added search, the client learned about neither, and the app rendered the first
twenty items of a list as though that were the list. Nothing was red, because
nothing could be.

Lifecycles joined the model too: a state machine is now declared rather than
implied, for work orders ([#846]), booking ([#848]), and invoicing, Manyfold and
the shop ([#849]). The concepts page for all of this was written and corrected
([#730]), along with the rule that an engine is composed **by call or by event**
and must say which ([#722]) — the plan and its typed-model spike are [#698] and
[#699].

## Engine calls are sub-transactions now

`ctx.atomic` ([#784]). Catching an error from an engine call used to be
forbidden outright, and for a good reason: the call runs inside *your*
transaction with no boundary of its own, so a bare `catch` leaves you holding the
partial writes its invariants were protecting, and then commits them.

```ts
try {
  await ctx.atomic(() => completeWorkOrder(ctx, { orderId, billable }));
} catch {
  // the engine's rows, events, links, grants and platform intents are all gone;
  // your own writes survive, and it still commits once
}
```

A succeeded `atomic` is still provisional — if the operation later throws, its
writes go with it. Sub-transactions nest but must not interleave; starting two
concurrently throws. Outside `ctx.atomic`, catching an engine error remains
forbidden.

## Module code lost the wall clock

Time comes from `ctx.now()` ([#851]). `new Date()` and `Date.now()` in module
code are now boundary-lint **R6** violations — the same class of ban as `node:*`.

The value is stable for the whole invocation, so a row and the event announcing
it agree about when. A host takes a `clock`, which is what lets a scenario assert
elapsed time with `manualClock` instead of sleeping or shrinking the window to
zero. Code that genuinely needs the real clock — a JWT whose `exp` a remote
server judges — opts out with a reviewable `boundary-lint-allow R6` block.

**This one will break existing module code**, deliberately and at lint time
rather than in production.

## A conformance kit, and what it found

Every engine now declares its operation surface, and a kit checks the handlers
honour what they declared ([#762]). Getting there meant breaking a require cycle
in `engine-protocol` — input schemas moved to their own leaf, a scripted move
verified against `main` at 70 exported names with none dropped.

Extending the kit to six more packages ([#889]) found the reference
implementation misdeclared, which is the outcome that makes a kit worth having:
the thing everyone copies was the thing that was wrong.

## Reads learned a vocabulary

`searchables` became an index the kernel builds and `ctx.search` reads ([#832]),
with the Todo demo declaring search and carrying a code on refusal ([#836]). A
list read now declares the filters and sorts it accepts ([#855]) rather than
accepting whatever a caller sends. A page's walk moved out of the body and into
response headers ([#837]), a paged read can carry a total opt-in, and a read's
query string is documented while a `GET` stops claiming a request body ([#834]).

## The docs became something an agent can read

`llms.txt`, `llms-full.txt` and a markdown twin of every page ([#765]), emitted
from the same sidebar the nav renders from, so a page nobody indexed cannot go
quietly missing. The rules an agent must not violate are now published, with the
index oriented around them ([#766]), and there is one page describing how any
agent discovers and works with Substrat ([#767]). Every page was refreshed
against its source, and freshness itself made mechanical ([#759]).

On the agent's side of the seam: a scaffolded project announces itself and pins
to its own kernel ([#773]), the skills travel to projects we never scaffolded
([#788]), and an agent can start the dev servers and verify its own change
([#778]) instead of trusting a green test suite.

## Also landed

**Scaffolding and the CLI** — the scaffold a user actually gets now runs in CI
([#856]) instead of being trusted, and the template is compiled against the
workspace ([#882]), which is the gate that makes a breaking engine surface red in
its own PR. A scaffolded project passes its own gates again ([#874]), scaffolds
against what we ship with pins that stop drifting ([#796]), and the deployed
surface is the one you developed against ([#839]). The ambient `cloudflare:workers`
env stopped counting as a capability ([#864]) — one import handed module code
every binding and secret the script declared. A UI the push would never serve is
refused ([#884]), a dev server that cannot work refuses to boot ([#857]), and the
design document settled on one name, `spec/concept.md` ([#854]).

**Local auth** — `@substrat-run/dev-issuer` ([#885], [#886]): a real OIDC provider
whose only shortcut is that `/authorize` lists names instead of asking for a
password. A vertical no longer needs a dev auth branch, and changing issuer is a
change of `OIDC_ISSUER`.

**Platform** — pushed verticals can declare tracing ([#870]), and a version's
declared egress is checked against what it actually reached ([#879]). A refusal
before egress stopped being reported as the provider's ([#850]), a store that
cannot be minted answers with a diagnosis ([#838]), and a declared per-tenant
store now reaches the tenants that already exist ([#826]). In the console, an
auto-admitted version says so and the vouch has a button ([#869]), and a narrow
viewport keeps its buttons ([#872]).

**Connectors** — a declared connection grant repairs itself without touching the
credential ([#845], [#843]); the Scrive catalog could not grant `protocol:read`
([#728]). Scrive sends the vertical's document rather than an attestation sheet
([#716]), the account holder is the sender and never silently a signatory
([#853]), and a signature request can carry how a party is reached, sealed to the
connector ([#745], [#703]) — an address, not a personnummer. The document-store
caveat turned out to describe calls this connector already uses ([#706]).

**Host and contracts** — a permission denial is a 403 and the mount has a seam
([#794]), `mountOperations` types the values a URL carries ([#787]), `http.method`
accepts `PUT` ([#780]). A dependency policy landed, with zod as a peer where it
belongs ([#761]), and required per-worker secret keys are marked so a blank one
cannot ship ([#782]).

**Builder** — the model phase, with the direction rule made mechanical ([#718]),
and a build phase that reads the approved model ([#719]). Eval fixtures can start
at the prompt, so the interview itself is measured ([#764]). A token budget, and
a refusal for the escapes that once rewrote the monorepo ([#768]); the command
deny-list is asserted rather than executed ([#774]); scratch projects stay out of
the repo's own gates ([#776]).

**Docs** — the enforcement story got its own page ([#887]), five diagrams landed
with the engine machines read from the code ([#876]), and the diagrams reach
`llms.txt` ([#873]). `docs/` moved into strategy, architecture, engines, rfc and
briefs ([#792]), the decision log became files with every status verified
([#790]), the internal corpus got a gate and three missing engine docs ([#793]),
D-46's DO limit was clarified as enforcement-only rather than invisibility
([#883]), Convex got its own comparison entry ([#772]), and the design-interview
skill learned to decide the auth seam ([#781]). The acceptance benchmark was
retired and D-28's dual-emit clause narrowed.
